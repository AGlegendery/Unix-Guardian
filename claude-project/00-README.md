# پک دانش پروژه‌ی Unix Guardian

این پوشه هر چیزی رو داره که ایجنت بعدی (Claude در Claude Projects یا Claude Code)
برای ادامه‌ی کار لازم داره: رودمپ تأییدشده، تصمیم‌ها و جواب‌هات، وضعیت دقیق هر
تسک، معماری واقعیِ ساخته‌شده، چیزهایی که روی لپ‌تاپت اندازه گرفتیم، باگ‌هایی که
پیدا و درست شدن، محیط توسعه، قواعد کار، برنامه‌ی سخت‌افزار AMD و سؤال‌های باز.

## چطوری توی Claude Projects بذاریش

۱. توی claude.ai یک Project جدید بساز (مثلاً «Unix Guardian»).

۲. فایل `PROJECT-INSTRUCTIONS.md` رو باز کن و متن داخل کادرش رو توی بخش
**Instructions** پروژه بذار.

۳. همه‌ی فایل‌های `.md` این پوشه رو به **Project knowledge** آپلود کن (فایل
`PROJECT-INSTRUCTIONS.md` لازم نیست آپلود بشه، چون متنش رو توی Instructions
گذاشتی).

۴. برای اینکه Claude کدِ واقعی رو هم ببینه، این دستور رو توی پوشه‌ی پروژه اجرا
کن و فایل‌های پوشه‌ی `source/` رو هم آپلود کن:

```bash
./scripts/make-knowledge-pack.sh
```

۵. هر بار که کد عوض شد، همون دستور رو دوباره اجرا کن و فایل‌های `source/` رو
توی Project جایگزین کن. وقتی کاری تموم شد از Claude بخواه فایل
`04-status.md` رو به‌روز کنه و نسخه‌ی جدیدش رو جایگزین کن.

> نکته: Claude توی Projects نمی‌تونه دستور اجرا کنه یا فایل‌های لپ‌تاپت رو
> ببینه. دستورها رو خودت اجرا می‌کنی و خروجی رو براش می‌فرستی — Instructions
> طوری نوشته شده که همین رو ازش بخواد. اگه بعداً با Claude Code توی همین
> پوشه کار کنی، فایل `CLAUDE.md` در ریشه‌ی پروژه به‌صورت خودکار خونده می‌شه.

## For the agent (English index)

Reading order: `04-status.md` → `02-decisions.md` → `05-findings.md` →
`07-conventions.md` → `03-architecture.md` → the rest as needed. The roadmap
(`10-roadmap.fa.md`) is the approved plan; `04-status.md` is the truth about
progress. Code lives in `source/*.md` (generated by
`scripts/make-knowledge-pack.sh`; the header names the commit).
